# Dr Asad Hussain — Academic Website

This is a static website prepared from the CV supplied in this conversation.

## Files
- `index.html` — website content and page structure
- `style.css` — visual design and responsive layout

## Publish with GitHub Pages
1. Open your `USERNAME.github.io` repository on GitHub.
2. Select **Add file → Upload files**.
3. Upload `index.html` and `style.css` from this folder (not the ZIP itself).
4. Commit the changes to the `main` branch.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/(root)`, then Save.
7. Wait a few minutes and visit `https://USERNAME.github.io`.

## Before publishing
- Check all wording, dates, publication details and links.
- The mobile number from the CV is intentionally not displayed on the public website.
- The original CV PDF is not included as a public download because it contains the mobile number. If you want a public CV download, first prepare a version with any personal details you do not want public removed, then upload it to the repository and add a link.
- The website currently uses your University of Reading email address, ORCID and Google Scholar link from the CV.
- The Google Fonts import requires an internet connection; the site remains readable with system fonts if it cannot load.
